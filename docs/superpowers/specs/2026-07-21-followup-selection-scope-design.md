# 待办队列分类选择范围设计

## 背景

当前待办队列使用一个跨分类共享的手机号集合保存勾选状态。用户在“逾期跟进”勾选客户后切换到“今日待跟进”，不可见的逾期客户仍会计入“已选”并可进入批量发送，存在误发风险。

## 已确认行为

- 勾选范围只属于当前分类。
- 切换到其他分类时，立即清空全部已选客户。
- 清空后批量操作栏隐藏，不能把上一分类的不可见客户带入批量模板流程。
- 在同一分类内，“全选”“反选”和逐条勾选保持现有行为。
- 点击同一个已激活分类不重复清空，也不影响当前选择。
- 通过工作台卡片、查看全部或实时提醒切换到不同分类时，执行相同的清空规则。

## 数据显示

本次不修改客户数据显示字段。真实数据接入后优先显示映射后的客户昵称；昵称缺失时显示“客户 + 手机后四位”。手机号继续脱敏，客户类型、跟进方向、预约门店和来源表按现有接口字段展示。

## 测试

- Store 测试：从逾期切换到今日时清空选择，批量事件不包含旧分类客户。
- Store 测试：重复点击当前分类时保留选择。
- 组件测试：切换分类后批量栏消失。
- 回归测试：当前分类的逐条选择、全选、反选和批量模板入口仍正常。
