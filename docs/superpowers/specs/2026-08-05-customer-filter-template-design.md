# 客户筛选模板设计

## 目标

提供一个独立的客户高级筛选模板，帮助确认筛选条件的分组、层级和操作方式；本阶段只做可视化预览，不接入真实查询，也不修改现有后台功能。

## 设计

- 使用客户查询页内展开的筛选面板，不使用弹窗。
- 第一行放高频条件：客户阶段、线索类型、意向等级和关键词。
- 第二行放业务归属条件：来源渠道、负责管家、意向门店、意向项目。
- 第三行放时间和到店条件：预约日期、最近跟进时间、下次跟进时间、是否到店。
- 第四行放标签条件：性格类型、身体关注、客户顾虑；标签使用可点击多选按钮。
- 面板底部提供查询、重置、导出三个操作，并显示当前已选条件摘要。

## 数据边界

筛选选项按现有数据库字段、标签目录和智能表格映射展示。模板中的示例值仅用于说明布局，不代表新增或修改线上数据。自由文本字段（备注、跟进记录、客户档案等）不做固定标签按钮。

## 验收标准

1. 用户能在同一视图看到条件和结果区域的关系。
2. 常用条件和标签条件有明显层级，字段不会堆成无意义的大卡片。
3. 移动窄屏时每组条件自动换行，操作按钮保持可见。
4. 预览文件独立于 `AdminConsole.vue`，不会调用后台接口。
