# 配置中心小白化改造设计

## 目标

在不改变现有米白、橙色视觉体系和已有配置键含义的前提下，让第一次使用管理后台的人知道每项配置是什么、怎么填写、保存后影响哪里。常用操作直接展示，技术参数按需展开。

## 界面调整

1. 企业红线明确提示“每行一条，按回车换行，不使用分号”，占位示例使用多行中文内容。
2. 输出格式模板增加中文示例，并提示已有默认内容时通常无需修改。
3. 数据同步策略使用口语化名称；仅把常用同步频率放在首层，超时、缓存、版本保留和刷新频率放入“同步异常时再调整”。
4. 图 4 改为一步式“连接企业微信智能表格”。首层只有“企业微信智能表格链接”输入框和“检测并保存”按钮，辅助文字明确说明“打开目标表格，复制浏览器地址栏里的完整链接，粘贴到这里即可”。同时强调“仅支持由企业微信 API 创建并纳入本系统的数据表；手动新建的普通智能表格不能直接连接”。系统自动识别文档、子表和视图，验证来源后显示已连接的表格名称。网关地址、密钥、重试、积压和告警沿用现有服务器配置，不要求用户填写，并收进“服务器部署配置”。
5. 识图模型改为下拉选择已经配置的识图环境；没有可用环境时仅显示“未配置”，并引导先新建识图环境。
6. 系统内置工作任务统一验收状态列宽，后台测试按钮和“需工作台验收”对齐。
7. 工作任务配置改用口语化中文：模型失败回落、回答变化程度、回答长度和给模型的任务说明。原始英文提示词默认收起，避免小白误改。
8. 删除配置中心内重复的 Skill 场景管理卡片，保留左侧独立“Skill 场景管理”入口和全部原功能。
9. 环境名称包含连续问号时视为已损坏：优先显示模型名，其次显示“名称无法识别，请重新编辑”；不猜测或覆盖数据库中的原名称。
10. 识图和 LLM 的“新增环境”统一改为“新建”。

## 信息架构修正

配置中心不能因为加入新入口而继续向下堆叠。页面默认只展示配置步骤、识图与 LLM 模型环境、系统内置工作任务、企业微信接入、提示词与规则。

- “企业微信连接方式”和“连接企业微信智能表格”组成同一行的左右两栏，默认可见。左侧选择服务器转发或直连，右侧粘贴本系统通过企业微信 API 创建的智能表格链接。
- “高级运行配置”默认折叠。展开后只显示低频配置分组入口，不直接渲染所有表单。
- 低频分组为“模型分工与调用统计”“Skill 服务环境”“Skill 运行保护”“识图运行限制”“数据同步”。同一时间最多展开一个分组，切换分组不重置任何草稿值。
- LLM 场景路由及调用统计归入“模型分工与调用统计”；Skill 环境归入“Skill 服务环境”；原 Skill、识图和同步表单分别归入对应分组。所有保存、启用、测试、删除和刷新接口保持不变。
- 服务器部署参数仍位于智能表格区域内部的二级折叠中，不与日常表格链接输入同时展开。

## 数据与兼容性

- 企业红线继续按换行拆分并保存为原 JSON 数组，不接受分号作为隐式分隔符。
- 新增后端链接解析与验证接口：接收完整智能表格链接，解析文档、子表和视图标识，通过现有企微网关读取表格信息，并只接受可证明由企业微信 API 创建且已纳入本系统的数据表。
- 检测通过后复用现有数据源保存和替换能力，更新目标表格标识；网关配置仍决定服务器怎样访问表格服务，不与目标表格信息混为一项。
- 网关、同步、任务开关和提示词继续写入现有配置键，不改变后端消费者。
- 识图环境下拉使用现有 `/admin/api/v1/image-environments` 数据；选择后沿用现有环境启用接口，确保地址和密钥同步切换。
- 删除的是重复入口，不删除 Skill 场景 API、路由、数据或独立管理页。

## 错误与空状态

- 没有识图环境时，下拉框禁用并显示“未配置”，旁边提供“新建”入口。
- 链接为空或无法识别时提示“请打开目标表格并复制浏览器地址栏里的完整链接”。
- 表格不是由企业微信 API 创建、未纳入本系统或无法通过现有网关读取时，显示对应中文原因，不保存目标表格。
- 已损坏的环境名称只做显示兜底，编辑保存后使用用户填写的新名称。
- 高级参数保留当前值；折叠或改名不会重置已有配置。
- 关闭高级运行配置时收起已打开的低频分组；再次展开时从简洁的分组入口开始。

## 验证

- 前端测试覆盖十项文案、折叠状态、对齐结构、下拉空状态、表格链接检测和原配置键保存。
- 后端测试覆盖链接解析、API 创建来源验证、未纳入系统、手动创建表格拒绝、网关失败和检测成功后的数据源更新。
- 回归测试覆盖识图环境启用、LLM 任务开关、提示词保存、Skill 场景独立入口和高级参数保存。
- 运行完整前端测试、类型检查和生产构建。
- 在真实后台桌面宽度检查米白橙色主题、弹窗、折叠区和无重叠布局。
- 在真实后台检查企业微信两栏处于同一视觉行，且高级配置展开后不会一次性出现所有长表单。
